
# Student Management System

A student record management web application built using React.js.

## Features
- Add student records
- View student records
- Edit student details
- Delete student records
- Search students by name
- Dashboard with student and department counts
- Persistent storage using browser Local Storage
- Responsive user interface

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Local Storage

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.
